# NOVA TECH — AI-Powered Agentic Commerce

> An AI-powered commerce platform that helps merchants increase revenue through intelligent product recommendations, upselling, cross-selling, and secure Razorpay payments with complete auditability.

---

## 🚀 Project Overview

**NOVA TECH** is an AI-powered e-commerce application built around the idea of **Agentic Commerce**.

The application allows a customer to:

- Browse technology products
- Search products by name, description, category, or tags
- Filter products by category
- Add products to a shopping cart
- Increase/decrease product quantities
- Ask an AI shopping agent, **Nova**, for product recommendations
- Receive personalized product recommendations
- Discover cross-sell and upsell products
- Add recommended products directly to the cart
- Complete payments using **Razorpay Test Mode**
- Verify payments securely on the backend
- Handle failed payments gracefully

For the merchant, the application provides an **analytics and audit dashboard** showing:

- Total revenue
- Successful orders
- Orders created
- Average order value
- Failed payments
- Number of Nova AI queries
- Payment conversion rate
- Verification attempts
- Complete audit trail of important system events

The main goal is to demonstrate how an AI agent can participate in commerce while ensuring that **every money-related action is explainable, bounded, verified, and auditable**.

---

# 🎯 Problem Statement

Traditional e-commerce platforms require customers to:

1. Search through many products
2. Compare products manually
3. Decide what they need
4. Find complementary products
5. Proceed through a conventional checkout flow

This creates unnecessary friction.

NOVA TECH introduces an AI shopping agent that allows users to simply describe their needs.

For example:

> "I need a wireless mouse under ₹1,000 for my workspace."

Nova analyzes the request and recommends suitable products from the available catalog.

The agent can also identify complementary products and provide:

> "You may also want..."

This creates opportunities for:

- Personalized shopping
- Higher average order value
- Upselling
- Cross-selling
- Conversational commerce
- AI-assisted purchasing
